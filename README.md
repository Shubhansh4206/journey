# Journey 🌍

Journey is an AI-powered travel ecosystem designed to solve the operational nightmare of personalized tour planning. It shifts the industry from rigid, pre-packaged tours to dynamic, collaborative, and AI-driven experiences.

## 🏗️ System Architecture (Monorepo)

* **`backend/`**: The AI Brain (FastAPI + LangGraph). Manages the Multi-Agent System (Planner, Procurement, Pricing, Disruption) and Supabase sync.
* **`web_operator/`**: Operator Command Center (Next.js + React). The dashboard for tour operators to review AI quotes, adjust margins, and approve live itinerary changes.
* **`app_traveler/`**: Traveler Interface (Flutter). The mobile app for group leaders to build trips, solo travelers to join them, and everyone to view live interactive routes.
* **`supabase/`**: Local Supabase CLI configuration for database and auth synchronization.
